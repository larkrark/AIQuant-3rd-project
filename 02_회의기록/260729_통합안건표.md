## 1. 읽는 법 — 3축 + 정합성

김근형 상태분류표의 3등급(형태 갖추어짐 / 일부 정리됨 / 논의 필요)은 **완성도**를 잰다. 여기에 **승인**·**담당**·**정합성** 축을 분리해 붙였다. 안건마다 고유 상태 리터럴을 만들지 않고 조합으로 표현하므로 새 enum이 늘지 않는다.

### 축 1 — readiness (완성도) · 김근형 표 3등급 그대로

| 코드 | 의미 |
|---|---|
| `FC` | FORM_COMPLETE — 개념·근거·잠정안·담당 또는 후속 절차가 있음 |
| `PA` | PARTIAL — 방향은 있으나 파라미터·적용 범위·예외 처리가 부족 |
| `UD` | UNDEFINED — 정의·담당·승인 절차·처리 방식 중 하나 이상이 불명확 |

### 축 2 — approval (승인) · 데이터사전 기존 enum 그대로

`NR` NOT_REQUESTED / `AP` APPROVAL_PENDING / `APV` APPROVED / `REJ` REJECTED

### 축 3 — ownership (담당)

`OA` OWNER_ASSIGNED / `HO` HANDOFF_TO_REVIEW_OWNER / `ON` OWNER_NEEDED

담당자는 역할 배정 v1.1(2026-07-22) 기준. **김근형**=PIT 규칙·상태 데이터·공시 식별자·인계 / **추주원**=인디케이터 구현·분포·하한 후보 / **권보성**=백테스팅 실행·BM/환율 데이터 명세·전 트랙 검토보조 / **김민호**=QA·성과 평가·발표 제출 주관 / **전원**=회의 의결 항목.

### 축 4 — 정합성 (신규)

완성도가 높아도 결정로그와 어긋날 수 있으므로 분리한다.

| 값 | 의미 |
|---|---|
| `일치` | 결정로그 확정 내용과 문서가 같음 |
| **`충돌`** | 결정로그 확정·기각 내용과 문서가 어긋남 |
| **`삭제`** | 결정로그 확정문이 신버전에서 사라짐 |
| **`ID없음`** | 실질 규칙인데 결정로그 D-번호가 없음 |
| `–` | 대조 대상 아님(신규 사실확인·실무 항목) |

### 김근형 표의 권장 상태 ↔ 3축 대응 예

| 원 표기 | 3축 조합 |
|---|---|
| `LECTURE_BACKGROUND_CONFIRMED` | `FC` / `AP` / 김근형 `OA` |
| `PILOT_ONLY_NOT_PRODUCTION_APPROVED` | `FC` / `AP` / 추주원 `OA` |
| `UNRESOLVED_WITH_OWNER_NEEDED` | `UD` / `NR` / `ON` |
| `PILOT_CONFIRMED_WITHIN_SEED18 / PRODUCTION_APPROVAL_PENDING` | `FC` / `AP` / 추주원 `OA` |

### ID 정책

`AG-nn`은 **본 표 전용 임시 정리번호**다. 의결된 항목은 결정로그 `D-YYYYMMDD-NN`을 부여하고 `AG-nn`은 폐기한다. 기존 라벨 7종(`T-`·`H-`·`S-`·`U-`·`F-U`·`D-U`·`M-`)에 하나를 더 얹지 않기 위한 조치이며, 라벨 일원화 자체는 AG-57에서 다룬다.

## 5. 이 표를 쓰는 방식 제안

1. **회의 시작 5분** — 0단계 사실 확인 4건을 닫는다. 의결이 아니라 확인이므로 빠르다.
2. **정합성 열이 `충돌`·`삭제`인 24건** — 각각 "확정 복원 / 변경 승인 / 표기 오류 정정" 세 갈래 중 하나로 판정한다. 판정만 하고 세부 문구는 담당자에게 넘겨도 된다.
3. **담당 열이 `ON`인 항목** — 회의 중 담당을 붙인다. 현재 AG-64 1건이며, 나머지는 역할 배정 v1.1로 특정 가능하다.
4. **의결된 항목** — 결정로그에 `D-20260729-NN`을 부여하고 `AG-nn`은 폐기한다.
