## 4. 오늘 논의와 회의안 사이 확인이 필요한 지점

1. **theme_eligibility_status의 성격**: 회의안 D-2는 "분리된 축", 오늘 채팅은 "별칭이라면 재논의 불가". → **해소(§7)**: 데이터사전 429행 확인 결과 gate_status로 대체된 읽기 호환용 별칭(신규 산출물 사용 금지). 같은 필드이므로 D-2의 "독립 축 유지" 질문은 성립하지 않아 회의안에서 해당 문구·질문 삭제 예정.
2. **미국 BM 안건의 프레임**: 회의안 D-4는 유지 전제에서 보조 BM 병기까지, 오늘 제안은 공식 BM 재선정으로 확대. 김민호 의견서(K: Russell 3000 유지 + D-08 사전 기록 + 한계 병기)와 입장이 갈리므로, 오후 회의에서 "유지 vs 재선정"을 선택지로 명시해 다뤄야 한다. 어느 쪽이든 §0.1 성과기반 변경금지 준수 논리(방법론 정합화 vs 성과 동기)의 검증이 필요하다. **미해소 — 회의 의결 대상.**
3. **PR 산식(연결계수·제수조정) 의결의 소속**: 회의안 닫을 질문에 없음 → D-1에 추가할지 별도 안건으로 세울지 결정 필요 (김민호 추가제안 ①과 병합 가능). §7에서 "1.1e-15는 자기재현이지 동치증명 아님, 감사 추적성을 근거로 선택해야"로 양측 합의 — **의결 필요성은 오히려 강화됨.**
4. **P10 논의의 범위**: 회의안 D-3은 결측·정지 정책 틀 안에서 P10 모집단만 다룸. → §7에서 수학적 근거 확정: h(P10)=(n-1)×0.10<1이면 P10 미만은 항상 정확히 1종목(n≤10에서 항상 성립) — P10은 유동성 임계가 아니라 '최저 1종목 탈락' 장치. 4회차 실측 전부 일치, KTOS(6/30 315.15M, 탈락)가 ATI(3/31 234.03M, 편입)보다 34% 큰데도 탈락한 실증 포함. D-3 닫을 질문에 이 구조 문제 추가 요청됨. **정책 선택은 미해소 — 회의 의결 대상.**
5. **라벨 정리**: 오늘 제기된 우선확인 1~7·의결필요 ①~⑤가 회의안 D-번호와 다른 체계로 통용되기 시작함. 오후 회의에서 결정ID(D-20260727-XX 형식 권장)로 일원화하지 않으면 기존 회의 D-1~D-9 vs 결정로그 D-번호 충돌에 라벨 체계가 하나 더 늘어난다.
6. **한국 BM 문구(추가 확인됨, §7)**: 룰북 v0.4 257행·결정로그 318행 — KOSPI 200 PR이 확정 유지(D-13 ③), KRX 300은 "최종 구성종목에서 KOSDAQ 비중이 유의한 경우 재확인" 시의 대안 후보. 회의안 표기는 현행 룰북과 일치. 다만 **트리거 조건인 KOSDAQ 비중을 측정할 listing_board 필드가 seed_basket.csv에 없어** 조건 발동 판단 자체가 불가 — listing_board 필드 추가를 D-2 enum 작업에 포함하자는 제안이 나옴(N-5와 연결되는 선결과제).

2. **PIT 붕괴(look-ahead 실재)** — 2021FY는 정정본(2021-06-02)만 보유. 자료마감일이 2021년 3~5월인 회차를 조회하면 그 시점에 존재하지 않았던 정정 후 숫자를 반환.
3. **같은 날 문서 구분 불가** — 010120은 원공시·정정공시 접수일자가 둘 다 2026-02-05로 회사·보고서명·날짜가 전부 동일. 접수번호만 다름.
4. **파일명은 출처 식별자가 아님** — target_name·original_name은 우리가 만든/다운로드 시점 이름. DART가 문서에 1:1 부여하는 키는 접수번호뿐(앞 8자리=접수일자로 자기기술적).
5. **제3자 검증 불가** — 출처주소규칙(DART-EVID-001)이 증거 보존을 요구하는데 source_path가 로컬 경로라 검증 담당이 대조 불가. 접수번호가 있으면 dart.fss.or.kr rcpNo URL로 누구나 동일 원문 열람.
6. **산출값이 실제로 바뀜** — 010120을 원공시 숫자로 계산하면 3.33:1, 정정본으로 계산하면 5:1. 어느 버전을 읽었느냐가 계산 결과를 바꾸는 **계산 정확도 문제**(기록 정리 문제가 아님).

**회의 상정 문구**: 공시자료 추적원장에 **rcept_no(문서 키) + source_url(재현 경로) + parent_rcept_no(정정 계보)** 3개 컬럼 추가. — D-8(bitemporal·amendment 계보)·N-5(데이터 거버넌스)와 직결되며, §7의 "공시 원문 접수번호 확보 중"(D-1 분할 근거) 문제의 구조적 해법.
