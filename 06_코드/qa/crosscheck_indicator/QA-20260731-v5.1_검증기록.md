## 5. 7건 대조

| | v3 지적 | v5.1 상태 | 근거 |
|---|---|---|---|
| ① | `quick_ratio=1.2` 기본값 주입 | 해소 | 부재 시 `INPUT_NOT_AVAILABLE` 분리 |
| ② | `methodology_decision_id` 임의 생성 | 해소 | `DECISION_ID_PENDING` |
| ③ | P10 모집단에 시즈닝 미필터 | 해소 | `CALCULATED` 필터 → US n=8 |
| ④ | `OBSERVE` 등급 | 해소 | 2단계 + 축별 사유 기록 |
| ⑤ | `official_adtv90` fallback 오산 | 해소 | `traded_sum/(n−miss)` |
| ⑥ | `missing_days_90` 역산 | 해소 | 직접 카운트 |
| ⑦ | QA 상태값 하드코딩 | 해소 | 호출자 주입 · `RUN_ID_NOT_PROVIDED` |

### 분모가 룰북 189행 R6 그대로다

```python
traded_sum = win.loc[s == "TRADED", "daily_trading_value"].sum()
official_adtv90 = traded_sum / (n - miss)
```

```
값에 기여      TRADED 만
분모에 포함     TRADED · ZERO_VOLUME · TRADING_HALT   (정지·무거래는 0 반영)
분모에서 제외   DATA_MISSING
```

정지일을 분모에서도 빼는 대안을 `adtv90_exclude_halt_diagnostic` 으로 병기했다.
QA 가 `stage7_recompute` meta 에 `halt_treatment_alternative` 로 남긴 것과 같은 취지이며,
D-12 ⑤ 진단 병기 원칙에 맞다.

## 6. 잔여 2건

### 6-a. 결과 저장이 Windows 에서 죽는다

```python
with open(f"{__file__.rsplit('/', 1)[0]}/crosscheck_result.json", "w") as f:
```

Windows 경로 구분자는 `\` 라 `/` 로 나뉘지 않는다. 전체 경로가 그대로 반환되어
`...\crosscheck_vs_engine.py/crosscheck_result.json` 을 열려다 `FileNotFoundError` 로
종료된다. **대조 계산은 끝난 뒤라 콘솔 출력은 정상이고 저장만 실패한다.**

커밋된 `crosscheck_result.json` 의 `crosscheck_target` 이
`/mnt/user-data/uploads/...` 인 것과 정합한다 — POSIX 환경에서 생성됐다.

수정

```python
import os
out_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "crosscheck_result.json")
```

**팀 다수가 Windows 이므로 재생성이 막힌다.** 값 자체에는 영향이 없다.

### 6-b. `MARKET_CLOSED` 가 창에서 빠지지 않는다

```python
listed = g[g["daily_market_state"] != "NOT_LISTED"]
win = listed.tail(Config.OPEN_DAYS_TARGET)
```

`NOT_LISTED` 만 제외한다. QA `stage7_recompute` meta 정의는
`excluded_from_window: [NOT_LISTED, MARKET_CLOSED]` 다.

**현 파일럿에서는 무해하다.** 실제 상태 분포에 `MARKET_CLOSED` 가 0건이다.

```
TRADED         3125
NOT_LISTED      175
TRADING_HALT      3
MARKET_CLOSED     0
```

다만 휴장 행이 포함된 입력이 들어오면 90행 창이 실제로는 더 짧은 기간을 덮게 된다.
**지금 고쳐두면 나중에 조용히 틀리는 일이 없다.**
