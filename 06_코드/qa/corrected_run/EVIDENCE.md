정지 3거래일 · 재개일 · 정지 중 종가 캐리 · 재개일 거래량 급증(21배)이 모두 보도와 일치한다.

- 이론 기준가 = 788,000 ÷ 5 = **157,600원**
- 재개일 종가 179,200원 = 기준가 대비 **+13.71%**
- 보도 헤드라인 "액면분할 후 첫날 13% 껑충"과 일치한다.

**분할 미반영 시 지수가 인식하는 수익률: 788,000 → 179,200 = −77.26%.**
이것이 실재하지 않는 하락이며, 편입비중 5.5556%로 지수에 반영돼 있다.

## 3. 발생 원인 — 데이터 결손이지 규칙 결손이 아니다

`run_meta.json`이 `valuation_price_source = RAW_CLOSE_FALLBACK`으로 기록하고 있다.
D-07은 이미 **지수 평가를 수정주가로** 하도록 정하고 있으며, `adj_close`를 확보하지 못해
`raw_close`로 폴백한 상태다. 즉 **규칙은 이미 옳고, 입력이 비어 있다.**

따라서 보정 사유는 `INPUT_ERROR_FIX`(입력 오류 정정)이며 성과 개선이 아니다(R3 저촉 없음).

## 4. 보정 재산출

### 4.1 명세 재현으로 신뢰성부터 확인했다

보정본을 믿으려면 **보정하지 않은 상태를 먼저 그대로 재현**할 수 있어야 한다.
`run_meta.json`의 세 줄 명세만으로 공표 산출물을 재구성했다.

| 항목 | 명세 | 재현 결과 |
|---|---|---|
| 연결 방식 | `SEGMENT_RELINK` (연결계수 체인, 제수 조정 아님) | 지수 59일 최대 상대오차 **1.056e-15** |
| 환율 적용 | `SAME_DAY_ECOS` (평가일 당일) | 〃 |
| 산출일 | `COMMON_OPEN_ONLY` (한·미 공통 개장일) | 공통 개장일 **59일** = 공표 산출일수 일치 |
| 합성 BM | KOSPI200 PR 50% + Russell3000 PR 50% | 최대 상대오차 **2.184e-16** |
| 환율 결측 | — | 59일 중 **0일** |

부동소수점 한계 수준까지 일치하므로 **명세가 완결적**이다. 이 위에서만 보정을 얹었다.

> 재현 과정에서 확인한 사실 하나: 합성 BM의 미국 구성분은 **평가일 당일 환율로 원화 환산**된다.
> 환산 없이 지수레벨 비율만 쓰면 공표 BM과 2.4e-02 어긋난다. 커스텀 지수가 원화·무헤지이므로
> BM도 같은 통화 기준이어야 비교가 성립하며, 이 처리는 옳다. 다만 어느 규칙 문서에도 명시돼 있지 않아
> **문서화가 필요하다**(추가 안건 대상).

### 4.2 보정 방법

데이터사전 4.1의 분할 전용 조정을 적용했다. 효력일 **이전** 가격을 분할비율로 나눈다.

```
P_adj(t) = P_raw(t) / 5      (t <  2026-04-13)
P_adj(t) = P_raw(t)          (t >= 2026-04-13)
```

배당은 건드리지 않는다. 야후 `Adj Close`는 배당 포함 TR 성향이라 PR 지수에 직접 쓸 수 없다(데이터사전 4.1).
다른 편입종목·BM·환율·가중치·편입판정은 **일절 변경하지 않았다.** 단일 변수 보정이다.

### 4.3 결과

| 구분 | 종가 레벨 | 누적수익률 | BM 대비 |
|---|---:|---:|---:|
| as-run (분할 미반영) | 1,271.1384 | +27.11% | **−14.66%p** |
| **5:1 분할 보정** | **1,337.7491** | **+33.77%** | **−8.00%p** |
| 합성 BM | 1,417.7850 | +41.78% | — |
| **보정 효과** | +66.61 | **+6.66%p** | **+6.66%p** |

민감도: 가정을 4:1로 낮추면 보정 효과는 +5.00%p(BM 대비 −9.67%p)다.
**액면가 근거로 5:1이 확정되므로 4:1은 채택하지 않으며, 폭의 감도만 참고용으로 남긴다.**

정밀값: as-run −14.6647%p → 보정 −8.0036%p, 효과 +6.6611%p.
(이전 공유본의 −14.67 / −8.01은 반올림 자리 차이이며 동일 산출이다.)

## 5. 인용 제한 — 왜 "검증 전"인가

`corrected_run_meta.json`에 `status = QA_REFERENCE_ONLY`로 기록했다. 아래 세 가지가 남아 있다.

1. **D-7 산출물 게이트 미통과** — 공표 산출물이 아니다. `qa/corrected_run/out/`에만 있고 `data/pilot_run/`에 등록하지 않았다.
2. **공시 원문 미확보** — 근거가 언론 보도 3건이다. DART 접수번호·원문이 붙어야 §5 근거자료의 요건을 충족한다. **이것이 회의 전 남은 유일한 실무 과제다.**
3. **엔진 재산출이 아니다** — QA가 명세를 재현해 얹은 보정이다. 편입판정·ADTV90은 재계산하지 않았다.
   분할은 효력일이 6/30 선정일 **이후 구간에 없고** 3/31 회차 관측구간 밖이라 편입 결과에는 영향이 없을 것으로 보이나,
   **확인하지 않았으므로 단정하지 않는다.** 엔진 측 정식 재산출로 확인이 필요하다.

> 따라서 **인용 형식은 "as-run −14.66%p / 5:1 보정 추정 −8.00%p(QA 참고본, 검증 전)"**로 병기한다.
> 보정본 수치만 떼어 성과로 제시하지 않는다.
