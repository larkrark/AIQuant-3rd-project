# 1. 프로젝트 스켈레톤 — 전체 맥락

이 파트만 발표하더라도, 전체 구조를 알아야 슬라이드의 용어가 이해됩니다.

## 1.1 무엇을 만드는가

**규칙 기반 패시브 커스텀 인덱스.** 사람의 재량이 아니라 문서화된 규칙만으로
구성종목과 비중이 정해지고, 같은 입력이면 언제 돌려도 같은 값이 나오는 지수입니다.

- 테마 3개 — 우주·방산 / AI·로보틱스 / 에너지·전력 인프라
- 지역 2개 — 한국 · 미국
- 3 × 2 = **6셀에 각 1/6** 배분, 셀 안에서는 편입 종목끼리 균등
- PR(가격지수) · 원화 · 무헤지 · 기준값 1,000
- 비교지수 = KOSPI 200 PR + Russell 3000 PR 합성 BM

## 1.2 파이프라인 7단계

```
1 유니버스      한국 코스피·코스닥 / 미국 나스닥·NYSE
2 테마 적격성   공시 근거로 테마 관련성 판정
3 게이트        증권유형 · 시즈닝(상장 후 유효관측 90일) · 유동성
4 상태코드      일별 6종 — TRADED / ZERO_VOLUME / TRADING_HALT /
                MARKET_CLOSED / DATA_MISSING / NOT_LISTED
5 인디케이터    ADTV90(90개장일 평균 거래대금) 등
6 구성·가중     P10 하한 통과 종목을 6셀에 배분
7 지수 산출     기준일 대비 가중 수익률 → 지수 레벨
```

## 1.3 문서 위계

```
Mandate (위임규정)  →  룰북  →  데이터사전  →  결정로그  →  engine 코드  →  산출물
```

규칙이 코드보다 먼저입니다. 코드가 하는 일이 곧 규칙이 되는 것을 막기 위한 구조입니다.

## 1.4 절대 원칙 두 가지

| 원칙 | 내용 |

| **PIT** (point-in-time) | 그 시점에 실제로 알 수 있던 자료만 쓴다. 미래 정보 유입 금지 |

# 2. 발표 규칙 — 슬라이드 문구에 반드시 반영

## 2.1 톤

- 성과를 자랑하지 않습니다. **검증의 밀도**를 말합니다
- 단정 대신 근거를 답니다. 모든 수치에 출처가 있습니다
- 한계를 먼저 말합니다. 숨겼다가 질문받는 것보다 낫습니다

## 2.2 절대 쓰지 않을 표현

| 금지 | 이유 |
|---|---|
| "검증을 통과했으니 결과가 정확하다" | 검산은 계산 정합성만 말합니다. 성과 신뢰와 별개입니다 |
| "제대로 된 유니버스였으면 더 좋았을 것" | 근거가 없고, 성과기반 규칙 변경으로 읽힙니다 |
| "완전 블라인드 검증" | 독립 재산출은 산출물 사전 열람이 있었습니다(`SPEC_ASSISTED`) |
| "성과가 낮다" / "성과가 좋다" | 통계적으로 알파가 0과 구분되지 않습니다 |

## 2.3 수치 인용 규칙

- 성과는 **항상 병기**합니다 — `as-run −14.66%p / 5:1 보정 −8.00%p (QA 참고본, 엔진 정식 재산출 전)`
- **6.66%p**(누적 수익률 %p 차)와 **5.24%**(지수 레벨 상대 차)는 다른 축입니다. 섞지 않습니다
- 소수점은 슬라이드에서 2자리까지만 보여줍니다. 정밀값은 발표 노트에 둡니다

## 2.4 디자인 방향

- 팀 네이비 `#1E2761`을 제목·강조에 사용
- 슬라이드당 **핵심 메시지 하나**. 텍스트를 문단으로 쓰지 않고 짧게 끊습니다
- 표는 4행 이내. 그보다 길면 요약합니다
- 강조 수치는 **크게 하나만**. 여러 개를 동시에 키우지 않습니다

## 페이지 5 — 유동성 하한이 유동성을 보지 않는다

**유형** 본문 · 표 + 수식블록 + 대비박스

**제목**
유동성 하한이 유동성을 보지 않는다

**부제**
계산이 맞는지만이 아니라, 규칙이 무엇을 하는지 확인했다.

**표**

| 회차 · 시장 | n | 최저 종목 | P10 대비 | P10 미만 |
|---|---|---|---|---|
| 3/31 KR | 9 | 018260 | −53.55% | **1종목** |
| 3/31 US | 8 | ATI | −22.17% | **1종목** |
| 6/30 KR | 9 | 018260 | −12.62% | **1종목** |
| 6/30 US | 8 | KTOS | −0.55% | **1종목** |

**수식블록** (제목: 우연이 아니라 구조다)
```
h = (n − 1) × 0.10

h < 1 이면 P10 은 항상 최솟값과 2번째 값 사이에 놓인다
  → P10 미만은 언제나 정확히 1종목
  → n ≤ 10 에서 항상 성립. 2종목 탈락은 n ≥ 11 필요
```

**대비 박스** (경고색)
> **KTOS** 6/30 `315.15M` → 탈락 　·　 **ATI** 3/31 `234.03M` → 탈락
> KTOS 가 **34% 큰데도** 떨어졌다.
> 절대 유동성이 아니라 **상대 순위**가 결정한다.

**마무리 한 줄**
→ 팀 안건으로 상정됨: "P10 을 절대 하한으로 볼 것인가, 상대순위 규칙으로 볼 것인가"

**발표 대사**
"규칙이 의도대로 작동하는지는 계산만 맞춰 봐서는 알 수 없습니다."
