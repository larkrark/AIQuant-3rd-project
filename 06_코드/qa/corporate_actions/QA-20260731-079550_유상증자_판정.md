## 2. 왜 이 건을 봤는가

기업행사 원장(v0.4 인계본)의 조회 종료일이 `2026-05-15` 였다.
파일럿 지수구간 종료(`2026-06-30`)와 06-30 회차 자료마감일(`2026-06-23`)보다
이르므로 **46일 사각**이 존재했고, 원장은 `079550` 을
`direct_issuer_event_count = 0` · `NO_ISSUER_EVENT_SUBSIDIARY_ONLY` 로 기록했다.

QA 사전조회 봉인(`345f43d`, 2026-07-31 10:09)이 이 구간의 발행회사 직접 공시
1건을 잡아두고 있었다. 봉인이 없었으면 사건 존재 자체가 확인되지 않았다.

## 3. 판정 근거 — 셋 다 단독으로 결론을 낸다

### 3-a. 제3자배정이므로 권리락이 발생하지 않는다

> 제3자배정에 대한 정관의 근거 — 제9조(주식의 발행 및 배정) 제1항의 2호

```
주주배정 · 무상증자   기존 주주에게 신주인수권 부여 -> 권리락 -> 기준가 조정
제3자배정            기존 주주에게 신주인수권 없음 -> 권리락 없음 -> 조정 없음
```

**가격 조정 사건이 아니다.** 010120 액면분할과 성격이 다르다. 액면분할은
주식수·액면가가 기계적으로 변해 가격계수가 필연이지만, 제3자배정은
기존 주주 지분에 신주인수권이 붙지 않으므로 기준가 조정 대상이 아니다.

### 3-b. 날짜가 전부 파일럿 구간 밖이다

```
이사회결의일        2026-06-25
공시                2026-06-26
납입일              2026-09-16      <- 파일럿 종료 2.5개월 후
신주권교부예정일     2026-10-07
신주의 상장 예정일   -  (미정)
```

주식수 변동이 `2026-09-16` 이후에 발생한다. 파일럿 구간
(`2026-04-01`~`2026-06-30`)에 반영될 경로가 물리적으로 없다.

### 3-c. PIT 상 06-30 선정 근거로도 쓸 수 없다

```
06-30 회차 자료마감일   2026-06-23
공시일                 2026-06-26   <- 마감 3일 후
```

결정로그 323행 D-13 ⑧(자료마감일 = 선정일 이전 제5거래일, 한·미 공통 개장일 축)에
따라 선정 입력에서 제외된다.

## 4. 부수 사실

> 제출을 면제받은 경우 그 사유 — 비상장주식의 사모 발행 및 전매제한조치(1년간 의무보유)

신주가 최소 2027년 9월까지 의무보유 대상이다. `신주의 상장 예정일 = -` 와 정합한다.
**유통 주식수 증가가 파일럿은 물론 상당 기간 지연된다.**

또한 본 지수는 균등가중(6셀 × 1/6, 셀 내 균등)이므로 주식수 변동이 비중에
직접 영향을 주지 않는다. 시가총액 가중이었다면 별도 검토가 필요했을 것이다.

## 5. 남기는 것 — 무영향이 곧 무기록은 아니다

**실데이터 구간이 2026-09 이후로 확장되면 주식수 사건으로 다시 검토해야 한다.**
