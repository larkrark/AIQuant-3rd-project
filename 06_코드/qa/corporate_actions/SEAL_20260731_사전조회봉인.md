```

```

**배정이 원위치됐으므로 독립성 강등은 철회한다.** 다만 QA 는 이미 조회를 마쳤고,
그 사실을 숨기면 나중 대조가 성립하지 않는다.

따라서 조회 결과를 **수집 담당의 원장이 도착하기 전에** 고정한다.
도착 후에 기록하면 "먼저 보고 맞춘 것"과 구분되지 않는다.

corp_code 3자 대조(2026-07-30)에서 `010120` 을 git 타임스탬프로
블라인드 증명한 것과 같은 방식이다.

## 4. 필터 한계 — 수집 담당께 반드시 전달할 것

**이미 아는 사건이 키워드 필터를 통과하지 못했다.**

`079550` 의 상호변경(구 사명 → 현 사명)은 QA 소견 F-2 로 이미 기록된 사건이다.
그런데 보고서명에 `상호`·`회사명`·`사명` 이 하나도 없어 필터에 걸리지 않았다.

실제 공시 경로는 이러했다.

```
2026-02-24  주주총회소집결의
2026-02-27  주주총회소집공고
2026-03-31  정기주주총회결과      <- 정관변경으로 상호변경
```

**보고서명 키워드만으로는 기업행사를 전수 포착할 수 없다.** 상호변경은 가격조정
사건이 아니라 식별자 사건이므로 지수 값에는 영향이 없으나, **같은 구조로 놓치는
가격 사건이 있을 수 있다**는 사실이 실증됐다.

보완 방향 — 주주총회 관련 공시(정관변경 포함)와 `기타경영사항(자율공시)` 를
2차 확인 대상으로 둔다. 본 봉인의 `dart_filings_raw.csv` 865건 전량이 그 확인에 쓰인다.
