## 4. 기록되지 않은 것 — 숨기지 않는다

### 4-a. 조문 근거 메모가 비어 있다

각 시트의 메모 열(`02!G`, `03-04!G`, `05!G`, `06!H`, `08!G`)에 근거가 적히지 않았다.
`기입가이드`·`README` 는 *"어느 조문을 근거로 했는지 적으십시오"* 를 요구한다.

따라서 **어느 조문을 보고 그 값을 냈는지가 워크북에 남지 않았다.**
값이 일치한 것은 확인되지만, 조문 인용 확인(README §9 체크리스트 5건)의
수행 여부는 이 산출물로 증명되지 않는다.

### 4-b. 워크시트 내 봉인 대조가 기입되지 않았다

`09 대조표` 의 `F`열(코드값)·`G`열(판정)·`H`열(불일치 원인)이 전부 공란이고
`D24`(일치 수)·`D25`(불일치 수)가 `0` 이다. `D26` 은 생성기 기본 안내문 그대로다.

즉 **봉인 파일을 열어 옮겨 적는 절차가 수행되지 않았고**, 대조는 QA 스크립트가
대신했다. 본 문서 §2 가 그 결과다.

### 4-c. 판단 ④ 의 근거가 기록되지 않았다

룰북 197행은 `P5·P10·P25·P50·P75` 산출 절차만 정하고 **보간 방법을 정하지 않는다**
(데이터사전·결정로그에도 없음). 선형보간은 QA 임의 가정이다(`MIGYEOL.md` U-2).

수행본은 선형보간 수식을 사용했으나 **그 방법을 선택한 근거가 메모에 없다.**
이 항목은 자의적 판단이 필요한 유일한 항목이었으므로, 근거 기록이 산출물의 핵심이었다.

### 4-d. 기록된 판단 — 판단 ③

## 5. 계산 과정에서 드러난 사실

값이 맞았다는 것보다 이쪽이 산출물이다.

### 5-a. KTOS 는 절대 유동성이 아니라 상대순위로 탈락했다

```
정렬 순번 1  KTOS   315,154,781.22   ← 최솟값
정렬 순번 2  ATI    317,626,170.96
P10 하한             316,884,754.04   ← 두 값 사이 70% 지점
KTOS 의 P10 대비     −0.545931%
```

`h = (n−1) × 0.10 = 0.7 < 1` 이므로 P10 은 항상 최솟값과 2번째 값 사이에 놓인다.
**최하위 1종목은 언제나 자기보다 높은 하한을 만난다.**

### 5-b. 2종목 이상 탈락에는 표본 11개가 필요하다 (`B43 = 11`)

```
h = (n−1) × 0.10 ≥ 1   →   n ≥ 11
```

Seed18 은 시장별 8~9종목이므로 **구조적으로 항상 1종목만 탈락한다.**
현재 규칙은 *"유동성 하한 미달 제외"* 가 아니라 *"최하위 1종목 제외"* 로 작동한다.

### 5-c. 셀에 종목이 1개면 비중이 3배가 된다

```
KR_AI_ROBOTICS     2종목  →  종목당  8.333333%
그 외 4개 셀        3종목  →  종목당  5.555556%
US_SPACE_DEFENSE   1종목  →  종목당 16.666667%   ← KTOS 혼자
```

3/31 회차에서 `SPCX`(시즈닝)·`ATI`(유동성)가 탈락해 KTOS 가 셀 전체 1/6 을 받았다.
**개별종목 상한과 셀 최소 종목수 규정이 없다.**

### 5-d. 자료마감일 기산점은 조문에 없다

결정로그 323행은 *"선정일 이전 제5거래일, 한·미 공통 개장일 기준 역산"* 이다.
`"이전"` 이 선정일을 제외한다는 독해로 6/23 이 나온다.

```
6/30 선정일 (세지 않음)  6/29(1)  6/26(2)  6/25(3)  6/24(4)  6/23(5)
```

두 회차 모두 이 독해와 일치한다(3/31 → 3/24, 6/30 → 6/23).
**다만 조문은 기산점을 명시하지 않으며, 스스로 *"정식 확정은 #30 적용시험 후"* 로
잠정 표기하고 있다.** 6/19 는 한국만 개장(미국 휴장)이라 세지 않는다 —
공통 개장일 축이 실제로 결과를 바꾸는 사례가 이 구간에 존재한다.

## 6. 룰북 정정 대상 2건

수행 과정에서 조문 자체의 문제가 확인됐다. 둘 다 표본 크기와 무관하다.

### 6-a. 룰북 218행 — "유일 행렬" 은 오류다

> 목표비중 행렬 | 테마×지역 6셀 각 1/6 [확정, D-10 ②] **(1:1:1과 50:50을 동시 만족하는 유일 행렬)**

반례가 존재한다.

```
        KR      US      테마합
우주   0.2000  0.1333   0.3333
AI     0.1000  0.2333   0.3333
에너지  0.2000  0.1333   0.3333
       0.5000  0.5000   ← 지역 50:50 · 총합 1
```

미지수 6개에 독립 제약 4개(테마 3개 중 2개 + 지역 1개 + 총합 1개)라 **자유도가 2** 다.

**값 1/6 은 D-10 ② 로 확정된 것이므로 유지하고, 괄호의 근거 설명만 정정**해야 한다.
`유일 행렬` → `1:1:1·50:50 을 만족하는 균등 배분 행렬(D-10 ② 채택값)` 정도가 정확하다.

### 6-b. 룰북 197행 — 백분위 산출 방법이 없다

> ADTV90 하한 설정 절차 [절차 확정, 숫자 대기]. 시장별 ADTV90 분포를 **P5·P10·P25(Q1)·P50·P75로 산출**하고 …

**어떻게 산출하는지가 룰북·데이터사전·결정로그 어디에도 없다.**
선형보간(`h = (n−1) × p/100`)은 QA 임의 가정이며 엔진도 같은 방식이라 일치했으나
**양쪽 모두 문서 밖이다.**

보간 방법을 바꾸면 P10 하한이 달라지고 편입 판정이 갈릴 수 있다.
데이터사전 또는 수식부록에 산출 방법을 명문화해야 한다.

## 7. 인용 제한

**계산 일치는 성과 신뢰가 아니다.**

```
표본 58일 · 추적오차 32.57% · 연율 알파 −25.25%
알파 표준오차 ±67.90%   →   t = −0.372
```

알파가 0과 구분되지 않는다. 구성종목은 규칙이 산출한 것이 아니라 시험용 Seed 18 이며,
전체시장 유니버스 구축은 `NOT_PERFORMED` 다(우선결정 안건 ⑧).

파일럿 지수구간(2026-04-01~06-30, 공통 개장일 59일)에 **리밸런싱 적용 이벤트는 0회**다.
선정은 2회 수행됐고(3/31·6/30) 지수에 반영된 것은 3/31 분 하나다.

```
발표에서 하지 않을 말
"검증을 통과했으니 결과가 정확하다"
"수기 검산으로 완전 블라인드 확인했다"     ← QA 가 대화 중 봉인값을 노출했다
"리밸런싱 로직을 검증했다"                ← 적용 이벤트 0회
```

**블라인드 한계.** 본 수행 전, QA 가 감사 게이트·README 검증 출력을 통해
봉인값 12개를 대화에 노출했다. 따라서 값 자체의 블라인드는 성립하지 않는다.
성립한 것은 **수행자가 원자료에서 직접 계산했다는 사실**과
**판단 ③ 이 독립적으로 기록됐다는 사실**이다.
