- 테마 적격성은 인디케이터가 아니라 필수 게이트입니다.

- 사업역할, 정량 노출상태, 최종 출력상태를 분리합니다.

- 공식 매출비중은 같은 기간·통화·단위·연결범위에서 비교 가능할 때만 사용합니다.

# 22. 변경관리·중단

- 규칙변경은 결정내용, 상태, 근거, 대안, 기각사유, 영향범위, 승인자, 결정일, 효력발생일, rule_version을 기록합니다.

- 성과를 확인한 뒤 유리한 규칙을 선택하는 사후최적화를 금지합니다.

- 일반 변경은 사전공지·영향분석·병행산출·독립 QA 후 효력을 발생시킵니다.

- 긴급 변경은 법령·거래소 조치·데이터 공급중단·명백한 계산오류 등 사전 정의된 경우로 제한하고 사후 지수위원회 승인을 받습니다.

- 지수 중단은 사유, 마지막 산출일, 후속지수, 자료보존, 라이선스·계약 종료, 이용자 공지를 포함합니다.
