# 0. 사전 사용 원칙

- 기본 필드는 규칙 실행에 필요한 값이고 기록 필드는 조사·판정·검증·인계과정을 보존하는 값입니다.

- 동일 의미를 여러 필드로 중복 생성하지 않으며 변경은 migration map으로 처리합니다.

- 수치 결측을 0으로 바꾸지 않고 미공개·미도래·수집실패·정의불일치·비적용을 분리합니다.

- datetime 필드에는 상태문자를 넣지 않고 precision/status 필드를 따로 둡니다.

- 공통 필드와 KR/US 확장필드를 분리하되 동일한 event_id·document_id·security_id로 연결합니다.
