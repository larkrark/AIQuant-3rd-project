- 수식은 공식 원문 사실과 승인절차를 대신하지 않습니다.

- 수정주가 공급자 산식과 프로젝트 기업행사 조정산식을 혼용하지 않습니다.

- 배당은 PR에 포함하지 않으며 공급자 수정종가의 배당조정을 그대로 사용하지 않습니다.

# 14. 정기변경·체인 리베이스

through boundary T

= pre_switch_level(T)  
/ raw_new_portfolio_level(T)

= chain_multiplier × raw_new_portfolio_level(d),  
d \> T

- 목표가중 재설정형 구조에서 divisor-adjust와의 수치동등성은 검증된 범위에서만 주장합니다.

- 주식수 변경과 정기변경이 겹치는 복합사건은 별도 시험이 필요합니다.

- 후속 공통개장일이 없으면 selection은 실행되어도 official application count는 0입니다.
